# 🗂️ Portfolio — Douglas Silva
### Analytics Engineer, Data Viz, Data Analyst
 
> Landing page de portfólio pessoal para apresentação de projetos em Engenharia de Dados, Visualização e IA.
 
---
 
## ✨ Sobre o projeto
 
Esta landing page foi desenvolvida como vitrine profissional para atrair contratantes e clientes, com foco em projetos da área de dados.
 
**Público-alvo:**
- Empresas e recrutadores buscando Analytics Engineers
- Clientes no [99freelas](https://www.99freelas.com.br) e [Workana](https://www.workana.com)
**Design:** Dark moderno com paleta azul/roxo/verde, responsivo (mobile-first), sem frameworks — HTML, CSS e JavaScript puro.
 
---
 
## 🏗️ Estrutura do projeto
 
```
portfolio/
├── index.html          # Página principal
├── css/

├── js/
│   └── main.js         # Interatividade (filtros, animações, nav)

```
 
---
 
## 🎨 Stack do projeto
 
| Camada | Tecnologia |
|--------|-----------|
| Estrutura | HTML5 semântico |
| Estilo | CSS3 (Grid, Custom Properties, animações) |
| Lógica | JavaScript ES6+ (sem dependências) |
| Ícones | [Tabler Icons](https://tabler.io/icons) via CDN |
| Fonte | [DM Sans](https://fonts.google.com/specimen/DM+Sans) (Google Fonts) |
 
---
 
## 📋 Seções da página
 
| Seção | Descrição |
|-------|-----------|
| **Hero** | Apresentação, badge de disponibilidade, skill bars animadas |
| **Stack** | Chips filtrável por categoria (Eng. Dados, Visualização, IA, Cloud) |
| **Projetos** | Cards com hover animado e badge de destaque |
| **Sobre & Contato** | Bio, links (LinkedIn/GitHub/Email) e métricas de impacto |
